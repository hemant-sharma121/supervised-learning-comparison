# Comparative Study of Supervised Learning Algorithms

## Project Overview
This project compares five supervised machine learning classification algorithms on the Wine Quality (Red Wine) dataset. The objective is to evaluate and compare the performance of different algorithms using identical training and testing conditions.

## Dataset
- **Dataset:** Wine Quality (Red Wine)
- **Source:** UCI Machine Learning Repository
- **Total Samples:** 1599
- **Features:** 11
- **Target:** Wine Quality (Binary Classification)

## Algorithms Used
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## Methodology
1. Data Loading and Preprocessing
2. Exploratory Data Analysis
3. Feature and Target Separation
4. Train-Test Split
5. Feature Scaling
6. Model Training
7. Prediction
8. Model Evaluation
9. Performance Comparison
